# Governance

## Mission

ClaimScout exists to make claim verification faster, more transparent, and more accessible.

## Maintainer model

At launch, the project follows a maintainer-led model.

### Maintainers are responsible for

- reviewing and merging pull requests
- setting release direction
- triaging bugs and security reports
- keeping the community healthy
- documenting decision rationale

## Decision making

- small changes: maintainer review
- medium changes: discussion in issue or PR before merge
- major product or governance changes: request for comments in `docs/` or GitHub Discussions

## Becoming a maintainer

Potential path:

1. consistent high-quality contributions
2. constructive community participation
3. demonstrated product and security judgment
4. invitation from current maintainers

## Transparency

Major roadmap changes should be recorded in issues, discussions, or roadmap updates.

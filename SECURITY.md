# Security Policy

## Supported versions

This repository is currently in pre-1.0 development. Security fixes should target the latest branch.

## Reporting a vulnerability

Please do **not** open public issues for security-sensitive problems.

- Security contact: `mdmahdimubasshir@gmail.com`

## What to include

Please include:

- affected component
- reproduction steps
- impact assessment
- proof of concept if safe to share
- suggested remediation if available

## Response goals

Target response SLA after public launch:

- acknowledgment within 72 hours
- triage within 7 days
- fix or mitigation plan within 21 days when feasible
